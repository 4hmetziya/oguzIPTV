How to get a key

İkisi de ücretsiz ve isteğe bağlı. Altyazı için anahtar şart değil; Subdl sadece ek bir kaynak, TMDB ise oyuncu/özet gibi ekstralar için.

Both are free and optional. Subtitles work without a key; Subdl is an extra source and TMDB adds cast, plots and similar extras.

TMDB anahtarı (v3)TMDB key (v3)
  1. themoviedb.org adresinde hesap aç (Google ile de olur) ve giriş yap.
  2. Sağ üstteki profilin → Ayarlar → soldaki menüden API.
  3. Yeşil + Oluştur düğmesine bas.
  4. "Kullanım amacı kişisel mi?" sorusunda Yes – This is for my own personal use only seç.
  5. Açılan kısa formu doldur (uygulama adı: oguzIPTV, açıklama: kişisel IPTV oynatıcı).
  6. Sayfada API Key (v3) görünür; onu kopyala. "Read Access Token" olan uzun metin değil, kısa olan.
  1. Create an account at themoviedb.org (Google works too) and sign in.
  2. Top right profile → Settings → API in the left menu.
  3. Press the green + Create button.
  4. For "Is the intended use for personal use?" choose Yes – This is for my own personal use only.
  5. Fill the short form (app name: oguzIPTV, description: personal IPTV player).
  6. Copy the API Key (v3), not the long "Read Access Token".
Subdl anahtarıSubdl key
  1. subdl.com adresinde Sign Up ile hesap aç (e-posta, kullanıcı adı, ülke, şifre; robot doğrulamasını geç).
  2. Giriş yaptıktan sonra hesap sayfanın üstündeki sekmelerden API'yi aç.
  3. Default key kutusundaki anahtarı Copy API key ile kopyala.
  1. Sign up at subdl.com (email, username, country, password; pass the robot check).
  2. After signing in, open the API tab at the top of your account page.
  3. Copy the key in the Default key box with Copy API key.

Anahtarı kopyaladıktan sonra yukarıdaki kutuya yapıştır ve "TV'ye gönder"e bas. Anahtarını kimseyle paylaşma ve ekran görüntüsünde gösterme.

After copying the key, paste it in the box above and press "Send to TV". Never share your key or show it in screenshots.
